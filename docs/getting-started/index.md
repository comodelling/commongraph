# Getting Started with CommonGraph

This section will help you get CommonGraph up and running, and understand the key concepts behind the platform.

## Quick Navigation

- **[Quick Start](quick-start.md)** — The fastest way to run CommonGraph locally
- **[Basic Concepts](concepts.md)** — Learn the fundamental building blocks

## What You'll Need

- Docker and Docker Compose (for the easiest setup)
- Alternatively: Python 3.13+, Node.js, and PostgreSQL
- A terminal and text editor
- About 10 minutes for the quick start

## First Steps

1. Clone the repository
2. Follow the [Quick Start](quick-start.md) guide
3. Read about [Basic Concepts](concepts.md)
4. Explore the configuration options in [User Guide](../user-guide/configuration.md)

## Questions?

If something isn't clear, check the main [User Guide](../user-guide/setup.md) for more detailed explanations.
